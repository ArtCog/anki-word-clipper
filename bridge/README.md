# Мост к подпискам

Позволяет расширению работать не на платном API-ключе, а на **месячных подписках**, которые у тебя уже есть: Claude Max через Claude Code, ChatGPT через Codex CLI, Google через Gemini CLI.

## Как это работает

Ни один из провайдеров не даёт обращаться к подписке по HTTP: подписка живёт внутри их официальных приложений. Зато у каждого есть собственный CLI, который уже авторизован твоей подпиской и умеет работать в headless-режиме (`claude -p`, `codex exec`, `gemini`). Это штатная, документированная возможность этих инструментов.

Мост это маленький локальный сервер, который принимает обычный OpenAI-запрос от расширения, передаёт текст нужному CLI и возвращает ответ в том же формате. Никаких перехватов токенов и обходов защиты: работают только официальные CLI на твоей машине, под твоим логином.

```
расширение → http://localhost:8770/v1 → claude -p / codex exec / gemini → ответ
```

## Запуск

```bash
node bridge/server.js
```

Сервер слушает только `127.0.0.1`, снаружи к нему не подключиться. Окно терминала должно оставаться открытым, пока пользуешься расширением.

## Настройка расширения

Попап → «Перевод» → движок **ИИ** → провайдер **«Мои подписки через мост»**. URL и модель подставятся сами, поле ключа оставь пустым.

Доступные модели (поле «Модель»):

| id | что вызывает | нужна подписка |
|---|---|---|
| `claude-opus` | `claude -p --model opus` | Claude Max |
| `claude-sonnet` | `claude -p --model sonnet` | Claude Pro/Max |
| `claude-haiku` | `claude -p --model haiku` | Claude Pro/Max |
| `codex` | `codex exec` | ChatGPT Plus/Pro |
| `gemini` | `gemini` | Google AI Pro |

Проверить, что мост поднялся: открой `http://localhost:8770/v1/models` в браузере.

## Чем платишь за качество

**Скорость.** Замеры на этой машине: Gemini по API отвечает за 1-2 секунды, мост через `claude-opus` за 15 секунд, `claude-haiku` иногда до 40 (CLI каждый раз стартует заново). Для одного трудного слова терпимо, для разбора абзаца ждать долго.

**Лимиты подписки.** Запросы расходуют тот же лимит, что и твоя работа в Claude Code. Перевод слов может съедать квоту, нужную для кода.

**Разумный режим:** держать Gemini по API как ежедневный движок, а мост включать точечно, когда попалось что-то сложное (идиома, юридический или технический оборот) и нужны настоящие мозги.

## Если не работает

- `unknown model "..."` — проверь имя модели из таблицы выше.
- Долгая тишина, потом ошибка таймаута — CLI ждёт авторизации. Запусти его руками в терминале (`claude`, `codex`, `gemini`) и залогинься.
- `gemini` ругается на project id — нужен повторный логин Gemini CLI, у остальных моделей это не мешает.
